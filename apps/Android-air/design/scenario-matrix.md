## Remaining-detail boundary

S rows are not discarded features and must be carried into the native implementation plan. They are not counted as completed interactive screens. This design delivery establishes a reusable concept plus the principal daily journeys; exhaustive UI parity requires another detailed pass through S states using actual Android capability evidence. The user can inspect every provided R/P composition immediately in the studio. Real participant validation is pending as documented in the common research protocol.
