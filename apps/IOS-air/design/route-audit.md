## Route contract

- Четыре root destinations. Вкладка возвращает в свою текущую разрешённую stack; повторный tap выбранной вкладки не закрывает документ и не стирает фильтр. Back закрывает верхний modal/selection mode, затем документ/detail, затем папку. Никаких скрытых переходов в соседний раздел.
- Search/filter/sort/group/path/scroll и originSurface сохраняются до lock. Search в файлах явно обозначает область; Notes — доступный в Files фильтр общего catalog. Переименование/перемещение обновляет identity-based selection, не ищет элемент по старому названию.
- Edit имеет origin. Cancel чистой формы возвращает сразу; dirty Cancel/Back/tab/swipe-dismiss спрашивает discard; отказ остаётся в draft. Save success показывает сохранённый объект и Back возвращает к исходному списку. Failure сохраняет draft. Lock очищает draft без вопроса.
- Read-only — ограничение авторизации, а не visual state. Оно сохраняется на descendants; просмотр/фильтры разрешены, mutation methods/submit заблокированы с объяснением. Context menu показывает только применимое; обычный toolbar может объяснить недоступность. Hidden long-press не является единственным путём к действию.
- Переход из Settings в Connections открывает соответствующий раздел с понятным возвратом к источнику; переключение root таба сохраняет его собственную историю. Native coordinator разрешает overlay → originating root явно.
- После background отсутствует возврат к старому имени/поиску/документу до входа. После нового unlock открывается безопасный root; прежний секретный navigation snapshot не восстанавливается. Сохранённые изменения остаются в vault; несохранённые утрачены и это объясняется без названия объекта.
- Внешние iOS picker/permission/provider операции имеют свой lifecycle outcome. Возврат из системного UI не равен автоматическому возобновлению session. При lock — обычный вход, затем повторный выбор по сохранённой политике; никакой тайной plaintext очереди.
- Desktop-only возможности не добавляются по наличию общего route. W1 capability manifest сверяет фактический iOS набор и причины unavailable. Тестируется capability denial, а не пустая/пропавшая кнопка без объяснения.

## Action budgets (design acceptance, not production measurements)

Считаем tap от уже открытого соответствующего root, не ввод текста и не обязательную авторизацию: Copy из password list — 1; открыть detail — 1; открыть OTP или Passkeys — 1; найти группы — 1; открыть Notes filter — 1; начать новую заметку — 2; открыть import passwords — 1; начать Add entry — 1. Native navigation не должна добавлять welcome/dashboard или обязательную настройку между этими шагами. Часто используемые действия не прятать только в long press.
